## 1. 项目概述

**迹忆旅图** 是一款面向年轻旅行者（18-35 岁）的智能旅游路线规划与社区分享平台。用户可以在旅行前规划路线、旅行中打卡记录、旅行后分享游记到社区，并借助 AI 助手获取个性化推荐。

本原型覆盖全部核心交互流程，使用单文件 HTML 实现，所有数据通过 `localStorage` 持久化。

### 技术映射

| 原型实现 | 实际项目 |
|---------|---------|
| localStorage | Go + Gin 后端 API |
| 单文件 HTML | uni-app + Vue 3 |
| CSS 变量 | SCSS Design Tokens |
| IIFE Store | Pinia 状态管理 |
| addEventListener | Vue 事件系统 |

## 2. 设计语言

### 2.1 视觉风格

融合三大设计系统的核心特征：

| 来源 | 借鉴要素 |
|------|---------|
| **iOS 26** | 液态玻璃（`backdrop-filter: saturate(170%) blur(24px)`）、超大圆角（20-28px）、半透明导航栏 |
| **鸿蒙 6.1** | 沉浸式氛围光（三层径向渐变光斑）、温暖暖色调背景 |
| **ColorOS 16** | 弹性缓动动画（`cubic-bezier(0.34,1.56,0.64,1)`）、点击涟漪、流体过渡 |

### 2.2 色彩系统

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色 | `#0DA5BF` 青蓝 | 按钮、链接、进度、选中态 |
| 成功 | `#34C759` iOS 绿 | 已完成打卡、进度环 |
| 警告 | `#FF9F0A` 橙 | 当前打卡点、脉冲动画 |
| 错误 | `#FF3B30` iOS 红 | 删除按钮、退出登录 |
| 信息 | `#007AFF` iOS 蓝 | 链接、次要操作 |
| 文字 | `#1C1C1E` → `#AEAEB2` | 主文字 → 占位符 |
| 背景 | `#FDF8F4` → `#F5F3F8` | 暖白渐变，营造温暖氛围 |
| AI 助手 | `#A18CD1` → `#FBC2EB` | 紫色渐变，区分于功能操作 |

### 2.3 毛玻璃使用原则

**仅以下元素使用 `backdrop-filter` 模糊**：
- 导航栏（sticky 定位）
- 底部 Tab 栏
- 弹层底部面板（modal sheet）

**卡片使用半透明背景但不模糊**（`rgba(255,255,255,0.50)` + 边框），保证性能且维持可读性。

### 2.4 动效规范

| 场景 | 缓动函数 | 时长 |
|------|---------|------|
| 页面切换 | `ease` | 0.28s |
| 按钮点击 | `cubic-bezier(0.34,1.56,0.64,1)` 弹性 | 0.2s |
| 弹层出现 | 同上弹性 | 0.35s |
| 卡片按压 | `scale(0.97)` | 0.25s |
| 涟漪扩散 | `ease-out` | 0.5-0.6s |
| 地图标记脉冲 | `ease-in-out` | 1.5-2s 循环 |

## 4. 认证模块

### 4.1 登录页

**页面路径**: `#page-login`

**功能流程**：
```
未登录状态 → 点击"路线"/"我的"Tab → 自动跳转登录页
           → 微信一键登录 / 账号密码登录
           → 登录成功 → 返回之前想去的页面（pendingTab 机制）
```

**视觉结构**：
- 品牌区：渐变 Logo + 应用名 + Slogan
- 微信登录按钮（绿色 #07C160，阴影）
- 分割线 "或"
- 账号密码输入框
- 登录按钮
- 底部协议链接

**交互细节**：
- 登录按钮带涟漪效果
- 注册表单默认隐藏，点击切换展开
- 注册时手机号自动补 `+86` 前缀（适配后端 E.164 校验）
- 注册成功后自动登录

### 4.2 导航守卫

```javascript
// 全局拦截逻辑
if (!isLoggedIn && name === 'routes') → switchTab('login')
if (!isLoggedIn && name === 'profile') → switchTab('login')
// 登录后 pendingTab 自动跳回目标页
```

- **点击已打卡标记** → 弹窗显示打卡内容 + 心情 emoji + 星级评分
- **点击未打卡标记** → 直接打开打卡弹层

## 9. 帖子详情与互动

### 9.1 帖子详情页

**页面路径**: `#page-post-detail`

**结构**：
- 封面大图（4:3）
- 作者名（可点击 → 用户主页）+ 发布时间 + 互动统计
- 正文
- 话题标签
- 关联路线预览卡片（可点击 → 路线详情）

- 已有评论列表（头像 + 昵称 + 内容 + 时间）

### 9.3 点赞/收藏/复用

- **点赞**：切换 ❤️/🤍，实时更新数字，数据持久化

- **复用路线**：一键复制路线所有打卡点到自己的路线库，Toast "已复制到我的路线"
